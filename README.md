# E-Commerce Data Analysis Dashboard

## Project Overview
This project presents an Excel-based dashboard analyzing e-commerce order data to understand delivery performance, customer ratings, payment methods, and order trends.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Dashboard Design

## Key Metrics
- Average Order Value
- Total Orders
- Average Delivery Time
- Average Customer Rating

## Insights
- Company-wise delivery time comparison
- Discount trends by customer age
- Payment method analysis
- Category-wise total orders
- Top cities by item count
- Company-wise total orders
